# Background music

Place a looping trivia / game-show track here as:

**`trivia-bg.mp3`**

Free sources (check each license):

- [Pixabay Music](https://pixabay.com/music/search/game%20show/)
- [Mixkit](https://mixkit.co/free-stock-music/tag/game/)

After adding the file, restart the Vite dev server. Music plays **only during an active game** (from Start Game through the final leaderboard). Use the 🔊 button during a game to mute/unmute.
